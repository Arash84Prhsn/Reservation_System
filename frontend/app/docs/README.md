# Frontend Technical Documentation

This directory documents the frontend architecture and the two main business areas of the Laboratory Reservation System.

- [`architecture.md`](architecture.md) — application structure, state management, API client, responsiveness, and localization.
- [`features/auth.md`](features/auth.md) — authentication, session persistence, route protection, and logout handling.
- [`features/reservation.md`](features/reservation.md) — desktop/mobile reservation flows, seat map, calendar, and booking lifecycle.

The repository-level [`README.md`](../../../README.md) contains setup and execution instructions.
